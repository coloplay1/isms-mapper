## 1.23.1（2026-10-29）

- 導入進度的每個未完成步驟，圓點下方直接顯示還沒完成的項目數（例如「待辦 4」），逾期的改善事項與適用性衝突用紅底標示；不用點開各步驟，就能看出哪一步還缺多少。滑過圓點會顯示該步驟的明細
